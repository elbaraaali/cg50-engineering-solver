Important limits
----------------
- CAS simplifier is deliberately limited to polynomials in x, degree <= 12, using +, -, *, ^ and parentheses.
  Unsupported symbolic forms are rejected rather than guessed.
- Motion-function menu uses x as the time variable (x = t).
- Numerical derivatives/integrals have finite numerical precision; results are checked for parser/domain failures.
- A native ENGSOLV.g3a was not produced in this runtime because the fxSDK/SuperH toolchain is not installed and this runtime cannot reach the external forge to install it.
